Setting Expectations for Translation, Grammar Tools, and AI

Use this page when you are deciding which language tools and AI uses to allow on an assignment.

About 8 minutes. Includes wording you can copy.

What students experience

Students use translation apps, autocorrect, grammar checkers, and AI chat tools every day, and most do not think of the first three as AI. The tools also blur the line themselves. Word’s Editor, grammar checkers, and translation sites now offer full rewrites next to simple corrections, often in the same panel.

So a syllabus line such as “AI is not permitted” leaves most of the question open. Is spell check allowed? A dictionary? Translating a reading? Two problems follow. Careful students stop using legitimate supports to stay safe, and multilingual learners are often in this group. Other students cross a line they did not know was there.

Variation adds to the problem. The MLA-CCCC Joint Task Force notes that differing policies across instructors make it hard for students to predict what is acceptable in their next class (2023, p. 8). The task force also cautions against restrictions that make writing for class very different from writing at work and in daily life (Recommendation 7).

Seven practices

  1. Put an AI use label on every assignment

    Use No AI, AI-supported, or AI-integrated, and name the allowed uses. The AI Label Maker (opens in a new tab) formats the label for Blackboard. Stating the task and criteria openly is central to transparent assignment design (Winkelmes et al., 2016).

  2. Ask about language tools separately from the label

    The label answers the AI question. It does not tell students whether a dictionary, spell check, or a translation tool is allowed. Add a Tools line that names each one. The task force lists dictionaries and grammar checkers among the existing tools English language learners rely on (2023, p. 10).

  3. Draw the line at who leads

    AI-supported means the student leads and the tool supports. A tool that gives information (a definition, a flagged error) supports. A tool that writes or rewrites the student’s sentences leads, whatever it calls itself, so it falls under the label. Say this directly. The task force warns that AI tools push writing toward a standardized English (2023, p. 7). A student’s own sentences, with their errors, are what you can teach from.

  4. Separate reading support from writing support

    Translating a reading to understand it is a different question from translating a draft into English. Many instructors would allow the first and not the second, but few say so. This is practitioner advice. We did not find a study that tests it directly.

  5. Name Copilot and say what to do when unsure

    Students and faculty have Microsoft Copilot through OCTC’s Microsoft 365. Naming the tool removes a guess, and an “ask me first” line makes the question safe to ask.

  6. Ask every student for a short use note

    A two-sentence note (what the student used, and what they did themselves) builds the habit of transparency the task force recommends (Recommendation 5). The MLA Student Guide to AI Literacy lists discussing one’s process openly as part of AI literacy. Ask all students, so that no group carries a special burden of proof.

  7. Do not treat detection scores or language differences as evidence

    The task force calls AI detection unreliable and biased, with false positives that can lead to wrongful accusations (2023, p. 7), and it urges caution about detection tools (Recommendation 4). Features of second-language writing are not signs of AI use, and neither is unusually polished writing from a student who used a permitted tool. If you have a concern, talk with the student about how the work developed.

Where students are starting

Many students already use these tools daily but have never been asked to sort them by who leads. Early in a course, show the Tools line on an example assignment and talk through one case of each kind.

Before and after

What changed

  • A ban became a label with named uses.
  • “Grammarly and translators” became a Tools line that separates the uses you allow from the ones you do not.
  • The rewrite line is stated. Students no longer have to guess where a grammar tool stops being a grammar tool.
  • “Academic dishonesty” became a use note and an invitation to ask. Your misconduct policy still applies. The assignment now answers the questions that lead to unintended violations.

Wording you can copy

Replace the text in brackets. Put the Tools line directly under the AI use label.

Tools line

Tools.

  • Dictionary: [allowed / not allowed]
  • Spell check: [allowed / not allowed]
  • Translating the readings: [allowed / not allowed]
  • Translating your own writing: [not allowed / allowed for (purpose)]
  • Any tool that rewrites your sentences counts as AI use. Follow the AI use label.

If you are not sure whether a tool is allowed, ask me before you use it.

Use note

At the end of your work, add one or two sentences: which tools gave you significant help, what you used them for, and what you did yourself. For example: “I asked Copilot to explain the difference between affect and effect. I corrected my sentences myself.”

For the syllabus

Each assignment has an AI use label and a Tools line. They can change from one assignment to the next, so check them every time. Using a dictionary, spell check, or a translation tool to understand a reading is different from using a tool to write or rewrite your sentences. If the directions do not answer your question, ask me. Asking first is always welcome.

Links for students

The first teaches students to check the label and the Tools line, and to ask “who leads?” The second gives two Copilot prompts that explain without doing the work. Before you use any tool on this assignment, read Translation, Grammar Tools, and AI: Check the Rules First.
